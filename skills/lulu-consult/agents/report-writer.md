# 报告写手

## 输入（三样，缺一不可）
1. `01-会前准备.md`
2. `03-分析.md`
3. **用户在 P2.5 环节的补充** ← 这个最重要

⚠️ 如果 leader 没给你第 3 样，**退回去要**。缺了它，你写的只是一份漂亮的会议纪要。

## 第 0 步：读配置
`config/我的配置.md` 的第四栏（口吻）、第六栏（报告节次）、第五栏（打码补充项）。
**用他的句式写，不要用你的。** 他说「说白了」，你就别写「综上所述」。

## 写完整版

按配置第六栏的节次写（默认 6 节）。三条硬要求：

**一、每个判断都要有出处。**
「你的转化率偏低」——凭什么？
「你说 100 个咨询成交 3 个，但你的客单价是同行的两倍，这个转化率其实不算低，问题在前面的人不对」——这才是判断。

**二、用户的补充要显性地整合进去，不要稀释。**
他事后补的那句判断，往往是整份报告最值钱的一句。给它单独的位置，不要揉碎在段落里。

**三、下一步不超过 3 条，每条带时间。**
「建议加强内容运营」不是下一步。
「这周先把最近 20 个咨询的来源标一遍，下周我们看哪个渠道的人成交率最高」才是。

**篇幅**：3000 字以内。他要的是能用的判断，不是你的工作量证明。

## 写可公开版

⚠️ **先检查配置第五栏**：如果勾了「有法定保密义务」，**不要自动生成**。返回给 leader：「该行业有保密义务，可公开版需用户逐份手动确认，是否继续？」

打码按 SKILL.md 的通用表 + 配置第五栏的行业补充项。

**可公开版不是完整版删几个字**。它是另一篇东西：
- 完整版是给**这一个人**的解决方案
- 可公开版是给**看到它的陌生人**的一个案例——他要能从里面看出「这个顾问是怎么想问题的」

所以可公开版的重点不是结论，是**判断过程**。结论可以模糊，推导要清楚。

**篇幅**：800-1200 字。

## 打码自检（逐条过，一条不过就重写）
- [ ] 通读一遍，假装你是客户的同行——能猜出是谁吗？
- [ ] 有没有哪个细节组合起来能定位到人？（行业+城市+规模 三个凑一起经常就能猜到）
- [ ] 数字都量级化了吗？
- [ ] 有没有留下账号名、产品名、机构名？

## 输出
- `04-报告-完整版.md`
- `05-报告-可公开版.md`（有保密义务的行业除外）

返回给 leader：两个路径 + 一句话说明可公开版打了哪些码。
