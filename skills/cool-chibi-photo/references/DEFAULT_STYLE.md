# 包内默认Q版画法 · 3.0.0-rc.3

普通照片装好后只需上传原照，说：

> 帮我用这个iluluskill P图，不加字。

不写模式或写标准版时按图直接适配；明确场景版才先选“没拍到我／宠物小物互动／人太小替换”，未答复不生图。

Agent自动定位、查看并实际使用[默认画法图](../assets/lulu-q-style.png)，不用读者重复上传或自己寻找风格图。来源与用途记录见[默认参考元数据](../assets/default-style.json)。

## 默认画什么

默认图由Lulu本次已认可的黑衣长发Q版玩偶互动效果整理为纯角色、去背景的画法示例；Lulu已明确允许这张选定Q版随Skill提供。它是画法参考，不是读者的默认身份。

沿用2.x与v3的角色规范：

- 细腻、圆润的二维彩色插画，统一干净线条，柔和体积阴影；不是写实换脸或自动做成三维娃娃。
- 大头、短躯干、短四肢。没有具体角色设计时，以约两头身为目标：头高与自然展开的身体高约1:1。
- 头高从头顶到下巴，身体高从下巴到脚底；不按长发、坐姿外接框、家具或道具量比例。已认可的角色比例优先，不以统一数值为由重塑原角色。
- 动作和情境可读优先于全身露脚；允许合理半身与自然遮挡。不为坐满椅子、够到物件或填满真人身高拉长身体。
- 入景不强制白贴纸描边；线条、描边与合适的接触阴影共同服务画面融合。

**只借画法，不照搬Lulu。** 不把示例里的脸型、眼型或闭眼笑、发型、发色、肤色、黑衣、坐姿、人数与动作硬复制给读者。读者身份、可见衣服、姿态、视线和道具按自己的原照及本批明确说明；示例闭眼不代表每张都要闭眼。

摄影背景仍是默认。保留真实宠物、玩偶、茶壶等对象，只给选定的Q版角色使用插画画法，不自动把整张照片或真实猫狗动漫化。背景柔和插画化、换景、文字和删人仍是各自独立的选择。

## 怎样覆盖或关闭

本轮明确要求、本图/本批已认可角色、读者自己的style参考或文字style_instructions优先于内置默认；按各自认可范围执行，不把互相矛盾的画风全部混进同一请求。

- 自己已有喜欢的Q版：上传并说明只借哪些画法/比例，或明确复用该角色；只搬位置时不借默认图重画它。
- 只想用文字定画法：写style_instructions，按本次文字要求执行，默认图不能反过来覆盖它。
- 不用内置参考：设置use_builtin_style=false；这只关闭包内画法图，不改变场景、衣服、背景或删人许可。

默认画法明确且没有冲突时直接做，不反复问风格。只有确实存在未解决的候选冲突，才先展示本次实际可读的参考，用当前可用原生选择工具或文字选项等用户答复；不编候选，不在超时后默认第一项。用户说“你决定”就按已给委托继续。

原照没拍到本人、但想加入“本人Q版”时，需要一张实际可读的本人身份照或本批已明确的本人角色。不能拿Lulu示例的脸充当读者本人；读者也可明确选择另行设计通用原创角色。身份照提供“是谁”，默认图只提供“怎么画”。未要求特定本人、又未给角色时，可说明采用通用原创小人后继续自动适配，不把缺少自备风格或角色库变成必选弹窗。

## Agent怎样真正用到这张图

**Codex / 本地Agent**

1. 从当前Skill目录读取assets/lulu-q-style.png与assets/default-style.json，先实际查看参考。
2. 未被本次自有画风覆盖、且use_builtin_style未关闭时，将该实际图片作为style参考传入图像工具，明确use_for只含画法与比例。不能只在提示词里写文件名就称已传图。
3. 同时查看并传入本次原照及真正需要的身份参考，逐张说明用途；没有冲突就继续正常场景路由。若包内图没找到，先检查完整安装或定位公开原图，不让读者每次重新寻找默认风格。

**Claude → Grok手动交接**

Claude也要查看这张实际包内图，把它列进按图1/图2/图3排列的实际附件清单；图号按本次实际附件数量确定。Claude整理完整提示词，默认图只借画法，身份与衣服动作来自读者自己的输入。

Claude网页若不能直接取得包内图，先提供可下载的实际图片附件，或给出[GitHub原始画法图](https://raw.githubusercontent.com/ilulu66/iluluskill/main/skills/cool-chibi-photo/assets/lulu-q-style.png)，让用户下载后实际上传Grok。只发文字描述或一个本地路径不算交付了参考图。

用户自己在Grok图片编辑入口上传原照和该实际参考，再粘贴提示词；本Skill没有Grok自动connector，Claude不能假装已替用户上传。完整步骤见[CLAUDE_GROK.md](CLAUDE_GROK.md)。选择默认画法不替代small_person的删人授权，也不将Codex请求当Grok API。

## 实际结果仍要看

这张参考用于统一起始画法，不保证每张结果都会自动保持人物、比例、衣服和接触关系。生成后仍按[QA.md](QA.md)检查：像不像本次角色、有没有串衣服/闭眼笑、身体是否被拉长、互动是否成立、背景和真实对象有没有误改。

技术检查、实际视觉检查、用户接受分别记录；既有玩偶效果的认可不等于rc.3新增内置参考流程已经端到端验证。没有实际运行的项目不写通过，整图编辑也不冒称严格像素保留或原资产无损搬运。
