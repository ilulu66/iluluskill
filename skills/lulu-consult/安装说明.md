# 怎么装

## 一行命令（推荐）

```bash
npx -y skills add ilulu66/iluluskill -g --all
```

这条命令会把「会客厅 skill」整箱装上——包括学习工坊（lulu-learn 六件套）和这个咨询流水线（lulu-consult）。

只想要咨询这一个：

```bash
npx -y skills add ilulu66/iluluskill/skills/lulu-consult -g
```

---

## 装完先做一件事（别跳过）

打开 `lulu-consult/config/我的配置.md`，**填完再用**。

这份配置决定了这条流水线在你手里跑出来是什么东西。不填，它只会给你通用废话。
最重要的是**第二栏「我的专业判断从哪几个维度切」**——写 3-6 条只有你这行的内行才写得出来的。

觉得难写？让 AI 采访你：

```text
读一下 lulu-consult/config/我的配置.md，
然后采访我，一次问一个问题，帮我把这份配置填完。
特别是第二栏，多追问几轮，别让我写得太泛。
```

---

## 验一下装好没

对你的 agent 说：

> **帮我准备一次咨询**

它应该先问你要客户情况，而不是直接输出一堆通用框架。
如果它上来就给你一套「商业模式画布」之类的东西，说明配置没读到——检查配置文件在不在 `lulu-consult/config/` 下。

---

## 目录长这样

```
lulu-consult/
├── SKILL.md              ← 主入口，流水线怎么跑
├── config/
│   └── 我的配置.md        ← ⭐ 先填这个
├── agents/
│   ├── prep-scout.md          会前侦察
│   ├── transcript-analyst.md  逐字稿分析
│   ├── report-writer.md       写报告
│   └── atom-miner.md          提炼经验原子
├── templates/
│   ├── 经验原子库.md      ← 复制到你的案例库目录
│   └── 能力标签索引.md    ← 同上
├── 安装说明.md
└── 怎么用.md
```

把 `templates/` 里那两个文件复制到你配置里写的「案例库位置」，流水线第一次跑就有地方写了。
