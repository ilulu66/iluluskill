# 竖版候选、轻贴纸与短文案

用于用户要求“加一些贴纸”“文字每张换”“单人可以考虑竖版”，或明确认可参考图里的对应效果。沿用本批次授权；尚未开启时保持简洁版。参考只是画风时，不自动复制它的文案、姿势和全部装饰。

## 1. 先定整图结构

1. 写出照片情境与要保护的动作/道具，确定原片能保住的主体范围。
2. 已允许优化版式时，比较原比例与4:5、3:4候选。单人且左右冗余较多可优先看竖版；合照、横向动作与环境叙事按实际画面决定。
3. 优先裁切原片，保住头、主要手势、脚和互动道具；原片本来缺失的部分不冒充完整。不要机械拉直刻意斜构图。
4. 仅靠裁切放不下时，使用已授权构图C的延展/完整前景组重排；不默认生成缺失身体，不拉伸原人像。
5. 先分配真人、右下Q版、短句和小点缀的位置，再制作资产。底图必须先单独看过，不能用大量装饰掩盖构图问题。

比例选择不是按“一个人＝竖版”硬套，也不一次交付所有比例充数；选一个最适合本次照片与用途的方案，必要时保留对照。

## 2. “文字随机”怎么执行

含义是**每张根据画面重新选句，不固定套某句话**。编译生图提示词前先选定实际文字，不把“随机写点英文”当成全部要求。

- 依据可见情境、氛围和剩余空间选一句主短句，必要时加一句小字。
- 中文通常4～10字、英文通常2～6词可作为起点，按字体和画幅调整；优先读得清。
- 文字风格随照片：日常松弛、旅行轻快、工作随手记录等。用词自然、拼写正确，避免无关励志口号反复套用。
- 不借配文编造地点、日期、职业、关系、经历或事件；没有证据的具体事实不写。
- 用户提供明确文案则原样使用；明确说不要字时关闭。语言以用户要求为先，参考只用英文时可沿用简短英文，但不是固定要求。
- 记录实际选句；下一张重新判断，不把上一张的文字固定成品牌口号。

可先在内部列两三句再选一条，不需要把每次选词变成用户审批。配文只是轻点缀，不能压过真实人物与Q版动作。

## 3. 小贴纸和人物Q版分开计数

人物Q版仍为右下**一组对应主角**。除此之外，可用2～5枚小爱心、星点、弧线或与场景相称的小元素作为设计起点，数量随留白调整。

- 少量集中呼应主句或Q版，形成主次；避免满屏平均撒点。
- 笔触、颜色与照片和Q版协调，手机整图仍能认出形状。
- 不随意加第二个角色、重复手机/行李等会被误认为场景内容的道具。
- 不遮真人脸、手势、关键互动部位、必要文字，也不遮Q版眼睛和手机。
- 不默认做成拼贴、相框、手帐贴满效果；只有用户明确选择该方向时才增加密度。

## 4. 独立装饰层

底图、Q版、文字/点缀分别保留。已有Q版动作正确时，改竖版、文案和小点缀不重新生成角色。

装饰可由可用图像工具生成真透明资产，再按当前宿主支持的精确合成方式放入留白。要逐字核对，不以图片生成成功代替文字验收。若宿主支持可靠字体排版，也可用其原生文字层；不能虚称有某种字体或透明通道。

推荐另存 `decor.png`，并在任务记录中增加：

```json
{
  "decoration": {
    "enabled": true,
    "authorization": "用户要求轻贴纸和每张变化的短文案",
    "caption_mode": "scene_specific",
    "actual_main_text": "执行时填写本图选句",
    "actual_secondary_text": null,
    "elements": [],
    "zones": [],
    "reference_scope": "只参考手写笔触、视觉密度和布局，不复制动作或固定口号"
  }
}
```

本包 `compose` 命令仍负责一组Q版的布局与保护检查，不自动生成文字、评估排版或安置多组装饰。装饰合成需用当前实际工具完成，并对所有叠加层重新验收。

## 5. 交付前检查

- 原场景、人物动作与关键道具仍能读出；横转竖有实际收益。
- 主短句与小字拼写正确，没有多余字、怪符号和固定模板残留。
- 真人、Q版和文字的主次清楚，小贴纸有留白，深浅背景上对比合适。
- 所有点缀完整入框，有安全边距；真人脸和Q版眼睛等重点区域不被装饰遮住。
- 保留无装饰底图和独立资产，记录Agent检查与用户接受状态。

仅因参考里出现眨眼比耶就把本图自拍改成比耶，或复制参考的新背景/品牌文字，都不算成功的版式迁移。
