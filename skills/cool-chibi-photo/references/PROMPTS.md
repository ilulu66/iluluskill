# 提示词编译与定向修改

## 1. 编译顺序

情境 → 本图身份/服饰 → 动作/视线/表情/手物接触 → 角色设计 → 补全边界 → 输出。每阶段只做对应图层；去掉未选的模式，花括号替换为本图事实，实际传入所引用图片。

```text
图1：当前原照，决定身份、衣服、情境、动作与核心道具。
图2：选定角色/画风参考，只决定绘画语言、头/躯干/四肢的相对大小。
图3（若有）：本轮编辑目标，已认可的贴纸。
情境：{谁在做什么，与什么互动，同时有什么动作/表情}
保留项：{已认可的画风、比例、衣服、情境}
修改项：{本轮唯一或相关联的修改}
设计补全：{用户允许的范围；其余自然遮挡}
检查：{本轮2–4个可观察的易错点}
```

用户修动作就锁角色设计，用户修比例就锁画风和情境，不能每轮重猜一套审美。引用旧图只保留认可项，不把旧错误继续复制。

```text
使用 $cool-chibi-photo。背景A、构图B。
原照决定人物和情境动作；我提供的效果图决定Q版画风、视觉比例和排版。

未见下装鞋子允许简洁设计补全，仅用于Q版。保存底图、透明贴纸、成品和参数。
```

## 3. 独立Q版资产

```text
仅生成独立真透明PNG贴纸，不输出照片。
图1内容原图，图2画风/身体结构比例参考。
情境：{scene_intent}；不可删除的互动道具：{essential_props}。
主角：{人数、每人发型服饰与特征}。
动作：{站坐/前倾、头部朝向、可见眼睛视线、表情、两只手分别做什么、人与物接触及遮挡}。
面部遮挡：{实际遮挡区域}；仍可见的五官：{可见区域及自然位置}。局部遮挡不抹除其他可见五官。{如已获授权，填写Q版层小幅调整手机/发丝以露出一眼的范围；完全隐藏的部位不强制补出}。
沿用图2的头/躯干/四肢相对大小、脸型概括、眼睛画法、线条与阴影；不复制它的站姿、眨眼、衣服或额外道具。
用此角色的短身结构完成原照动作；家具适配小人尺寸，不能拉长小人适配桌椅。
允许设计补全：{授权范围}；其余保留自然遮挡。{完整身体/已认可半身构图}。
恰好{N}个主角，肢体合理、可见手脚完整。清晰白描边、透明边距，{少量选定装饰或无装饰}，不加文字、背景矩形或其他主角。
```

## 4. 实际纠错案例：工作时顺手比耶

```text
编辑图1这张已选定画风和比例的小人；图2原照只提供本图情境和动作。
锁定图1的大头、圆润眼睛、短躯干短腿、发型、衣服和插画画法，不变成长腿或写实人物。
核心情境：坐在打开的电脑前工作，顺手向镜头比耶。
一只手自然连接肩肘并落在键盘/触控板；另一只手向镜头伸出比V，有适度近大远小。
双眼按原照侧望，嘴轻轻抿住，不自动眨眼。短腿自然弯曲成紧凑坐姿。
小桌、打开的电脑和凳子按小人比例制作；工作手与键盘接触，家具不过度抢主体。
裙子鞋款沿用本图授权设计，底图真人不参与本轮编辑。完整透明贴纸，必要工作道具与人物为一组。
```

这是情境示例，不给其他照片默认加电脑/裙子/坐姿；每张重新写scene_intent。

## 5. 定向修订

### 动作

```text
图1是已有角色设计，只按图2重摆动作。保留头相对躯干、大小腿的尺寸、脸型和画风。
还原{完整情境及动作关系}，弯曲原短腿，不拉长身体适配家具。
只改{本轮姿势/视线/手与道具接触}，其余认可部分保持。
```

### 比例

有选定图就实际传入，保持该角色的身体结构，只重新摆姿势；不要混入半写实方向。无参考且明确数值时，解释口径并调整结构。不能用坐姿外框/长发/桌椅高度验算，也不能删除关键道具来满足比例。

### 衣服

```text
仅替换已确认Q版的{衣服部位}为{本图最新服饰}。
锁住画风、脸、头发、比例、动作、人数、核心道具和透明边缘。不要编辑真人底图。
```

### 面部遮挡：手机自拍

先读图，列出被挡住和露出的面部区域；不要把“不能编造完整真人脸”编译成“Q版禁止出现眼睛”。仅当本图有可见眼部或用户要求适当露眼时，使用下面的定向修订：

```text
保留手机在脸前的自拍动作、持手机手与提包手的分工。
保留手机旁可见的一只眼和眉毛，位置自然，视线朝手机/镜面。
按本次用户要求，可只在Q版中略移手机或理开几根发丝，让这只眼睛可读；另一只眼仍可被手机遮住。
眼睛只能在脸部合理位置，不画在手机或头发上，不穿透道具；不变成整脸无遮挡或自动眨眼。
此处是插画补全，不声称恢复被挡住的真人眼部。真人照片底图保持不变。
```

若原照面部完全遮住且用户要求保留这种遮挡，就保留；不强制每张自拍露一眼。隐私遮脸要求优先。检查整图尺寸下是否仍能读出动作和可见神态。

## 6. 背景小优化与局部清理

### A：原场景光色整理

```text
当前无Q版照片底图是编辑目标。本轮背景A、构图{已选项}。
需要改善：{本图最明显的1～3项背景问题}；具体调整：{区域＋局部明暗/偏色/饱和度的克制调整}。
保留人物、关键道具、全部物体与文字、建筑线条、原场景和光向，材质纹理自然；不重画真人。
没有本次授权的裁切就保持同一画幅和倾角。清理偏色不等于删除物体，压低干扰不等于涂黑背景。
避免蓝皮肤、过曝窗户、HDR、粗重暗角、假散景和人物边缘光圈。已有Q版沿用，先交付无贴纸底图再合成。
若图像工具产生了结构或文字漂移，仅取允许的光色参考并使用原片细节完成调整，不交付重绘主体。
```

### B：选定对象清理

```text
仅制作背景局部修补，保持原场景{场景}。
清理对象/区域：{已选杂物或非主角路人}。
保留{情境与人和物的关系}，不删正在使用/抱持的物体，不换地点天气时间。
按原相机透视、光向和景深补齐背景，虚化仅作用于适当背景。
原前景会从源照片恢复，仅使用允许背景像素，不新增人物、Q版、文字或标语。
```

## 7. 背景C / 构图C

先读BACKGROUND_COMPOSITION.md，根据真实授权选填“新背景”或“延续原场景”，不同时要求两者。

```text
本轮仅制作{指定新背景/原场景延展背景}，不重画真人，不画Q版。
目标画幅{画幅}；场景{指定或授权推荐后选定的场景}。
保留的前景组{人物/宠物＋关键桌椅道具}，新画布位置与尺度{位置}。
相机高度与透视{条件}，光向与软硬{条件}，接触面及阴影{条件}，均需匹配原片前景。
画面仍表达{scene_intent}。右下贴纸使用{区域}，无需为它造整片空白墙。
不要新人物/动物、文字口号或未要求的道具。输出仅用于背景层，原前景将按一致变换合回。
```

## 8. 轻装饰与竖版

已授权时读 [DECORATION_LAYOUT.md](DECORATION_LAYOUT.md)。先定实际短句及空白区域，再生成独立透明装饰资产；不要把真人和Q版一起重新生成来加文字。

```text
仅生成透明手写文字与小贴纸资产，参考图只提供笔触和装饰密度。
主句逐字：{本图新选短句}；可选小字逐字：{短句或无}。
风格：{随照片确定的清楚、克制的手写笔触和配色}；装饰：{少量与本图相称的小元素}。
各组完整可分离、留透明间距，不生成照片、人物、额外Q版或背景矩形。
合成时位于{已计划留白}，避开脸、主要手势、互动道具及现有文字，检查实际拼写和移动端可读性。
```

“随机文字”落实为每张重新选择合适的短句并记录，不是不检查文字。参考的眨眼、站姿、道具与口号不自动迁入当前图。

## 9. 其他常用情况

- 合照：P编号一一对应、坐次左右和衣服不换，人多先确认范围；不默默删人或改成站一排。
- 宠物：原照决定趴坐、依偎、花纹眼色；参考只给卡通语言。遮挡部位不强行补到全部可见。
- 仅右侧白边：对已确认图确定性加右侧画布，不再生成、不拉伸、不重采样原有效区。
