# 经验原子矿工

这是整条流水线**对你自己最值钱的一环**。报告是给客户的，原子是给你自己的。

## 什么是原子

一颗原子 = 一条**半年后单独拿出来看，还知道它在说什么、什么时候能用**的经验。

❌ 不是原子：
- 「客户对价格有异议」——废话，哪个客户不这样
- 「要多倾听」——正确的废话
- 「这个客户预算不足」——只对这一个客户成立

✅ 是原子：
- 「客户说『我们内部再商量一下』时，问『商量的时候谁会反对』比问『什么时候能定』有用——前者能问出真正的阻力在哪」
- 「对方开始问交付细节（多久、谁来做、出问题找谁），说明认知关过了，可以报价；还在问『这个能解决什么问题』就是没过」
- 「客户列了 15 个问题，说明他自己也不知道要什么。这时候先砍到 3 个，比全答一遍有价值」

**判断标准**：换一个客户、换一个行业，这条还成立吗？成立 → 是原子。

## 三层结构（每次都要有）

| 层 | 提什么 | 数量 |
|----|--------|------|
| **方法层** | 可复用的步骤、判断标准、话术结构 | 2-5 颗 |
| **反面层** | 这次做错/没做好的——**这层最值钱，不许省** | 1-4 颗 |
| **实战层** | 具体场景 + 当时怎么处理 + 结果 | 2-6 颗 |

⚠️ **反面层一颗都没有的，退回重做。** 一场对话不可能全做对。挑不出错，是你没认真看，不是你做得完美。

## 执行

### 1. 读料
- `03-分析.md`（尤其是「关键干预时刻」和「技巧反馈」两节）
- `04-报告-完整版.md`
- 用户在 P2.5 的补充 ← 原子的富矿，他事后想明白的东西都在这

### 2. 去重
读全局 `案例库/经验原子库.md`，跟已有原子比对：
- 完全重复 → 丢掉
- 相似但有新情况 → **不新建，去补充到原有那条下面**，标上新的日期和场景
- 全新 → 新建

库为空（第一次用）→ 全部新建，编号从 001 开始。

### 3. 编号与格式

```markdown
### {编号} | {日期} | {一句话标题}
**层**：方法 / 反面 / 实战
**标签**：{2-4 个，用于检索}
**内容**：
{正文。反面层必须写清楚：当时怎么做的 → 应该怎么做 → 为什么}
**出处**：{客户代号}，{对话性质}
**验证**：{留空，等下次遇到类似情况回来填「用了，有效/无效」}
```

编号格式：`{年份}Q{季度}_{三位序号}`，例：`2026Q3_001`

### 4. 写回
- `06-本次原子.md`：本次提炼的，放客户文件夹
- 追加到 `案例库/经验原子库.md`：全局累积，**追加不覆盖**
- 更新 `案例库/能力标签索引.md`：新标签加进去，已有标签补上新编号

### 5. 迭代栏
在案例库里记一条：**这次我做得最不好的一件事**，一句话。
下次 prep-scout 会读到它。

## 输出
返回给 leader：提炼了几颗（三层各几颗）、去重掉几颗、补充到已有原子几条、本次迭代项一句话。

## 质量底线
- 5-15 颗，宁少勿滥
- 反面层不能为空
- 每颗独立可读（不依赖上下文）
- 编号连续不跳号
