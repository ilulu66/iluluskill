# lulu-learn-atom:原子提炼(切件装盒)

你负责把拆解层的论点变成**独立、可检索、可复用的知识原子**——讲座整理成整理版是"能回访",提炼成原子才是"能复用":写文章时按主题抽取,不用重读全场。

**本 skill 的铁律**:
1. 一个论点 = 一个原子,不混着写。原子必须自含:脱离原讲座语境也能读懂。
2. 每个原子带出处(讲座名/说话人/时间戳),观点是谁的写清楚——**讲者的话和用户的引申必须分层标记**,不许混。
3. 🔒 **外部认知原子进独立库,绝不写入咨询语料原子库**(那是用户本人咨询能力的库,外部讲座内容混进去=污染)。
4. 未知写未知;原话里没有的推论,标「我的引申」。

---

## Phase 1:提炼

输入:`2-拆解/` 全部细拆文件(论点清单/硬信息/分歧/金句)。每场讲座提 **10-20 个原子**(宁缺毋滥,重复观点合并)。

每个原子一个文件,落 `2-拆解/原子笔记/NN-<原子名>.md`:

```markdown
---
原子: <一句话论点>
来源讲座: <项目名>
讲者: <说话人>
标签: [<主题标签 2-4 个>]
---

## 论点
<讲者的论点,一段说清>

## 原话支撑
> [时间戳] 说话人:「逐字引文」

## 边界
<这个论点在什么条件下成立/讲者自己说过的限定;没有就写"讲者未给边界">

## 我的引申(可选)
<用户自己的联想/应用方向,明确标记是引申不是原话>
```

## Phase 2:去重与索引

1. 对本场原子互查重:同一论点换说法的合并。
2. 若项目所属领域已有全局讲座原子库(如 `03-记忆素材库/` 下的外部认知库、`08-高手思考录/` 相应人物库),问一句(一问,默认=只留项目内):

> **这批原子要汇入全局库吗?① 只留项目内 ② 汇入 <检测到的库名>**

汇入时:与目标库已有原子查重,新增的追加,冲突的(同主题不同观点)并排保留标注来源——**不覆盖旧原子**。
3. 项目内生成 `2-拆解/原子笔记/00-原子索引.md`:一行一原子(编号/一句话/标签),供快速检索。

## Phase 3:回填

在项目 `0-入口.md` 的产出清单加一行原子统计(N 个原子+索引链接)。整理版(weave)的「五大判断」应与原子库互链:判断引用的论点若已成原子,链过去。

## 开源版说明

全局库路径因人而异:首跑时问用户「你的知识原子库放哪?(没有就只留项目内)」,记住选择。本 skill 不预设任何库路径。
